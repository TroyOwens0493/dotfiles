# Explain in Simplified Technical English

Write the explanation in ASD-STE100 Simplified Technical English (STE).

- Use short sentences. Keep procedural sentences to 20 words or fewer and descriptive sentences to 25 words or fewer.
- Put one instruction or one idea in each sentence.
- Use the active voice and simple verb tenses.
- Use common words with one meaning. Use the same term for the same thing each time.
- Write instructions as commands. Put each step in its own numbered item.
- Keep technical names exactly as they are, such as file names, commands, functions, and product names.
- Use lists and tables when they make the explanation easier to read.

Apply STE to the explanation text only. Do not change code, quoted text, or command output.
