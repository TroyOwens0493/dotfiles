# Estimate work

Estimate the work in lines of code and codebase churn.

- Give the lines added, changed, and removed. Give a range when the size is uncertain.
- Break the estimate down by file or area when the work touches more than one place.
- Base the estimate on the actual code. Read the files that the work will change.
- State the main assumptions and the parts that could make the change bigger.

Do not give time estimates, such as hours or workdays, unless Troy explicitly asks for them.
