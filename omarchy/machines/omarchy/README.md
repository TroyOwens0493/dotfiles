# Local settings for omarchy

These files are copies of this machine's local settings. Paths below this
folder are relative to the user's home directory. They include Bash overrides,
shell and tmux colors, monitor settings, and local mise tools.

The installation guide does not load or link this folder. To restore a file on
this machine, back up its current destination, then copy the saved file to the same
relative path under the home directory. If the destination is a symbolic link,
copy to its target to preserve the link. Review monitor settings before use on
another machine.

These copies do not update automatically. Refresh the relevant copy and commit
it when the local settings change. Keep credentials and other private data out
of this folder.
